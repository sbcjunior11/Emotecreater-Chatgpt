# Optional Coconut Emote resource pack

This folder is reserved for a server-compatible resource pack. No textures are included because the live Coconut Network pack and its namespace/model assignments were not supplied.

Before adding assets:
1. Inspect the server's existing pack and pack format.
2. Choose a unique namespace (for example `coconut_emotes`).
3. Avoid replacing existing vanilla or server-owned model definitions.
4. Add original pixel-art PNG textures and item model definitions.
5. Test with the exact Minecraft client version used by the network.

The plugin currently falls back to vanilla item icons and remains usable without a resource pack.
